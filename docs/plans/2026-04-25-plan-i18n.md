# i18n Implementation Plan — Full UI 9-locale + Output Language Coupling

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 UI 语言从 2 locale (`zh-CN`, `en-US`) 扩到 **9 locale**（`en` / `zh-CN` / `zh-TW` / `ja` / `ko` / `fr` / `de` / `es` / `ru`），与 `OUTPUT_LANGUAGES` 一一对齐。`navigator.language` 自动探测、`useSyncExternalStore` 反应式、`'auto'` 输出语言耦合 UI locale、`'detect'` 选项保留旧 model-heuristic、AccountMenu globe 入口深链路、所有 user-visible 字符串 i18n 化（~150 keys × 9 = ~1350 翻译）。

**Architecture:**
- **Storage:** `config_uiLanguage: Locale` 类型扩展；`config_outputLanguage` 形状不变。一次性迁移 `'en-US'` → `'en'`。
- **Reactivity:** `useSyncExternalStore` 全局订阅集合，`useT()` Hook 触发组件重渲染；`t()` 全局函数 identity 不变（不放 useEffect deps）。
- **First paint:** 模块加载同步 `detectInitialLocale()` → 立即调一次 `notify()`（让 `<html lang>` 在 React first paint 之前到位）→ 异步 `chrome.storage.local.get` reconcile 老用户存储值。
- **Output 'auto' 耦合:** `langCfg('auto')` 在请求构建时读 `getLocale()`，返回当前 UI locale 的 entry；`'detect'` 显式保留旧 model-heuristic instruction。
- **Cross-tab sync:** `chrome.storage.onChanged` 监听器调用 `notify()`，让所有打开的 reader/popup/options surface 反应式同步。
- **Mid-stream 切语言:** in-flight 流不取消（D15）；下一次请求用新 locale；chat 历史在 `chatBasePrompt` 加锁定提示行（D16）抗历史锚定。
- **Picker UI:** 原生 `<select>`（eng review 砍掉自定义 LanguagePicker）；`<option>` 应用 D14 排序（探测 / 当前 / 其余按 declaration 序）；`font-family: var(--font-i18n-fallback)` 跨 OS 渲染一致。
- **Globe icon 深链路:** `window.open(chrome.runtime.getURL('options/index.html#language'))`，无需 `tabs` 权限；弹窗策略拦截时 fallback 到 `chrome.runtime.openOptionsPage()`。
- **Robustness:** `notify()` 订阅者错误隔离（D18），一个组件 cb 抛错不影响其他订阅者。

**Tech Stack:** TypeScript + React 18（已有；用 `useSyncExternalStore`/`useId`）。Vitest + jsdom（已有，无新依赖）。无 i18n 库——保留手写 `t()` 三级回退；9 locale × 150 keys 静态内联约 12-15KB gzip。无新 manifest 权限。

**Spec:** `docs/specs/2026-04-25-spec-i18n.md` — CLEARED by `/plan-design-review` 和 `/plan-eng-review`（score 6/10 → 9/10，0 unresolved；新增 D16-D19；删除 D6 自定义 picker；包括 2 条 CRITICAL 回归测试）。

- [ ] **Step 1: 实现 9 locale 映射**

```ts
function detectInitialLocale(): Locale {
  try {
    const raw = (typeof navigator !== 'undefined' ? navigator.language : 'en' || 'en').toLowerCase()
    if (raw.startsWith('zh-tw') || raw.startsWith('zh-hk') || raw.includes('hant')) return 'zh-TW'
    if (raw.startsWith('zh')) return 'zh-CN'
    const base = raw.split('-')[0]
    const known: Record<string, Locale> = {
      en: 'en', ja: 'ja', ko: 'ko', fr: 'fr', de: 'de', es: 'es', ru: 'ru',
    }
    return known[base] ?? 'en'
  } catch {
    return 'en'
  }
}
```

- [ ] **Step 2: 同步赋值（必须在 React first paint 之前）**

```ts
let currentLocale: Locale = detectInitialLocale()
```

- [ ] **Step 3: 异步 reconcile 块**

```ts
void (async () => {
  if (typeof chrome === 'undefined' || !chrome.storage?.local) return
  const stored = await chrome.storage.local.get('config_uiLanguage')
  const raw = stored.config_uiLanguage as string | undefined

  // 一次性迁移 'en-US' → 'en'
  if (raw === 'en-US') {
    await chrome.storage.local.set({ config_uiLanguage: 'en' })
    if (currentLocale !== 'en') { currentLocale = 'en'; notify() }
    return
  }
  // 返回用户的存储值（与探测值不同时）→ adopt
  if (raw && raw in messages && raw !== currentLocale) {
    currentLocale = raw as Locale
    notify()
  }
  // 否则：新用户（无存储值）或未知值 → 保留探测
})()
```

- mock `navigator.language='pt-BR'` → `'en'`（fallback）

```ts
const subscribers = new Set<() => void>()
function notify() {
  if (typeof document !== 'undefined') {
    document.documentElement.lang = currentLocale
  }
  subscribers.forEach((cb) => {
    try { cb() } catch (e) { console.warn('[i18n] subscriber failed', e) }
  })
}
```

- [ ] **Step 2: setLocale 加 notify**

```ts
export async function setLocale(l: Locale): Promise<void> {
  if (l === currentLocale) return
  currentLocale = l
  if (typeof chrome !== 'undefined' && chrome.storage?.local) {
    await chrome.storage.local.set({ config_uiLanguage: l })
  }
  notify()
}
```

- [ ] **Step 3: useT Hook**

```ts
import { useSyncExternalStore } from 'react'

export function useT(): typeof t {
  useSyncExternalStore(
    (cb) => { subscribers.add(cb); return () => subscribers.delete(cb) },
    () => currentLocale,
  )
  return t
}
```

```ts
import { getLocale } from './i18n'

function langCfg(code: string | undefined): OutputLanguage {
  if (code === 'detect') {
    return OUTPUT_LANGUAGES.find((l) => l.code === 'detect')!
  }
  if (!code || code === 'auto') {
    const ui = getLocale()
    return OUTPUT_LANGUAGES.find((l) => l.code === ui)
        ?? OUTPUT_LANGUAGES.find((l) => l.code === 'en')!
  }
  return OUTPUT_LANGUAGES.find((l) => l.code === code)
      ?? OUTPUT_LANGUAGES.find((l) => l.code === 'en')!
}
```
